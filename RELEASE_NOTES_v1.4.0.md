# Inhouse Read v1.4.0

- La estantería permite cambiar entre la vista de lomos y una vista isométrica con los libros girados en sus modelos 3D.
- La vista elegida se guarda en el dispositivo y se restaura al volver a abrir la app.
- El modo isométrico reserva el ancho real que ocupa cada libro proyectado, para que no se monten entre sí.
- Las baldas siguen siendo instantáneas 3D estáticas; en móvil limitan la resolución de renderizado y no mantienen animaciones gráficas activas.
